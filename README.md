# Озвучка для видео (Qwen Voice Studio)

Локальная студия озвучки для видеоуроков: готовые голоса и свои (клонирование по короткому образцу),
длинные сценарии с исправлением отдельных предложений, субтитры и главы для YouTube, перевод видео
с озвучкой. Всё работает на твоём компьютере: текст, записи и видео никуда не отправляются.

Здесь только архивы программы для скачивания.

## Скачать

Открой [последний выпуск](../../releases/latest) и скачай архив для своего компьютера:

| Компьютер | Файл |
|---|---|
| Mac на Apple Silicon (M1 и новее), macOS 14+ | `QwenVoiceStudio-…-macos.zip` |
| Windows 10/11, 64 бит (лучше с видеокартой NVIDIA от 6 ГБ) | `QwenVoiceStudio-…-windows.zip` |

Нужно около 12 ГБ свободного места и от 16 ГБ оперативной памяти.

## Установить

1. Распакуй архив. На Windows — в папку с коротким путём, например `C:\QwenVoice`.
2. Запусти `Start.command` (Mac) или `Start.cmd` (Windows). Первый запуск скачивает всё нужное
   в эту же папку: 10–40 минут, нужен интернет. Можно прервать — загрузка продолжится.
3. Дальше запускай «Озвучка для видео» в папке программы. Интернет больше не нужен.

Подробнее — `README.txt` в архиве.

## Обновить

В программе: **«? Справка» → «Проверить обновления»**. Программа заменит только себя; голоса, словарь,
история озвучек и модели останутся на месте. Папку вручную не заменяй.

Если у тебя версия 0.17 или старше (в «Справке» нет раздела с номером версии): распакуй новый архив
и запусти в нём **«Обновить.command»** (Mac) или **«Обновить.cmd»** (Windows) — он спросит, где лежит
старая программа, и обновит её.

`SHA256SUMS.txt` в каждом выпуске — контрольные суммы архивов; программа сверяет их сама.
